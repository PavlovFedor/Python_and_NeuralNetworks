# Проекты по Python и нейронным сетям

# 1) deep-learning-tensorflow
В данной папке представлены лабораторные работы, посвящённые созданию пользовательских слоёв нейронных сетей с использованием библиотеки TensorFlow (Keras API). Все реализации наследуются от `tf.keras.layers.Layer` и демонстрируют принципы инициализации весов, построения прямого прохода и интеграции с обучением моделей.

## Что реализовано
- **Полносвязный слой (Dense)** – с выбором функций активации: linear, sigmoid, ReLU, softplus, Mish. Сеть из трёх таких слоёв обучена на синтетическом наборе данных `make_classification` (бинарная классификация).
- **Слой пулинга (Pooling)** – поддерживает размер, шаг, тип паддинга (SAME/VALID), агрегацию (максимум, среднее, медиана), а также глобальный и канальный режимы. Протестирован на CIFAR-10 в составе свёрточной сети.
- **Свёрточный слой (Conv2D)** – реализован с параметрами: количество фильтров, размер ядра, шаг, паддинг, функции активации (linear, ReLU, sigmoid, softplus). Построена и обучена сеть из трёх таких слоёв на CIFAR-10/MNIST.
- **Рекуррентный слой LSTM** – кастомная реализация с поддержкой `units`, `return_sequences`, активаций (`activation`, `recurrent_activation`), ручным управлением состояниями (`h_t`, `c_t`). Модель из двух LSTM-слоёв обучена на задачах классификации последовательностей (IMDB, Reuters или синтетика).

Каждая работа сопровождается обучением модели, оценкой точности и визуализацией процессов.

## Используемые технологии
- Python, TensorFlow 2.x
- Scikit-learn (генерация данных)
- Наборы данных: CIFAR-10, MNIST, IMDB, Reuters


# computational-mathematics
В данной папке  представлены Jupyter Notebook с реализацией ключевых алгоритмов вычислительной математики. Каждый ноутбук содержит теоретическое обоснование, вывод формул и практическую реализацию на Python с визуализацией результатов.

## Охваченные темы
- **Ряды Фурье** – аппроксимация прямоугольного и пилообразного сигналов, вычисление коэффициентов, явление Гиббса.
- **Ряды Тейлора** – приближение функций (sin, cos, exp, ln(1+x)) с помощью символьных вычислений SymPy, визуализация сходимости.
- **Волновое уравнение** – численное решение и анимация распространения волны в струне.
- **Фильтрация сигналов с FFT** – быстрое преобразование Фурье, удаление шума, восстановление целевого сигнала.
- **Численное интегрирование** – методы прямоугольников и трапеций, сравнение точности, достижение заданной погрешности.
- **Уравнение теплопроводности** – аналитическое решение, численное моделирование, анимация остывания стержня.
- **Оценка плотности вероятности (KDE)** – ядерная оценка плотности, выбор параметра сглаживания, сравнение ядер (гауссово, епанечникова, треугольное).
- **Матрица ковариации-дисперсии** – построение на основе корреляции и стандартных отклонений, пример с акциями Московской биржи (MOEX).
- **Уравнение переноса с затуханием** – решение, визуализация бегущей волны с экспоненциальным затуханием.

## Используемые библиотеки
- `numpy` – численные вычисления
- `matplotlib` – построение графиков и анимаций
- `scipy` – FFT, статистические функции
- `sympy` – символьное дифференцирование и ряды Тейлора
- `sklearn` – ядерная оценка плотности (KernelDensity)
- `pandas`, `requests` – работа с данными MOEX
